What We Built

Multimodal Data Integration
Combined somatic mutations, copy-number amplifications & deletions, and gene fusions into a unified input representation.
💊
CFDE Dataset Integration
Cross-referenced model genes against the CFDE IDG Druggable Genome (Pharos/TCRD) to surface FDA-approved targeted therapies.
⚙️
Custom Model Architecture
Extended NeST-VNN with per-gene multi-omic feature layers and improved auxiliary supervision to boost predictive performance.
🏥
Clinical Feature Integration
Incorporated sample type, mutation burden, and fraction genome altered as clinical context for richer outcome modeling.
🤖
LLM Descriptive Interpretations
Per-patient pathway-level explanations generated by Claude via AWS Bedrock, surfaced through an interactive GUI explorer.
